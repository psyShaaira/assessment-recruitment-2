# Requirements: AI-Generated Feedback Email

## User Stories

### US-1: AI-Powered Feedback Email Generation
As a recruiter, I want the feedback email sent to candidates to be generated by AI from the structured feedback report, so that candidates receive a warm, professional, and easy-to-understand explanation of their assessment performance.

### US-2: Graceful Fallback on AI Failure
As a recruiter, I want the system to still send a feedback email using a static template if the AI service is unavailable, so that candidates are never left without feedback due to a technical issue.

## Functional Requirements

| ID | Requirement | Acceptance Criteria |
|----|-------------|---------------------|
| FR-1 | The system shall send the structured feedback (overall summary, topics, next steps) to the AI service to generate a candidate-friendly email body | AI prompt includes candidate name, assessment title, all feedback content |
| FR-2 | The AI-generated email shall use a professional but friendly tone, plain text only, no markdown | Output is plain text with no formatting marks |
| FR-3 | The AI-generated email shall address the candidate by first name and sign off as "The Psybergate Recruitment Team" | Email body starts with greeting using first name, ends with team sign-off |
| FR-4 | If the AI service fails for any reason, the system shall fall back to a static template | Email is still sent; a warning is logged; no error returned to staff |
| FR-5 | The candidate's full PII (email, last name) shall NOT be included in the AI prompt | Only first name is sent to the AI provider |

## Non-Functional Requirements

| ID | Requirement |
|----|-------------|
| NFR-1 | AI call timeout is governed by existing `GROQ_TIMEOUT_SECONDS` config (default 60s) |
| NFR-2 | Fallback adds no measurable latency beyond the static template render (~0ms) |
| NFR-3 | No new database migrations required |
